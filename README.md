# Customer_shopping_behaviour_analysis

Just wrapped up an end-to-end customer behavior analysis! 📊

🧹 Python (pandas): cleaned and prepared the data

🗄️ SQL: CTEs, window functions and CASE segmentation to answer 9 business questions

📈 Power BI: built an interactive dashboard to visualize the results

Key findings:

✅ 80% of customers are loyal, but only 2% are new

✅ 72% of repeat buyers aren’t subscribed yet

✅ About half of purchases use a discount, even among high spenders

My recommendation: convert repeat buyers to subscribers, target discounts more selectively, and invest in new-customer acquisition.
